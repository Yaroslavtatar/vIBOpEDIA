# План реализации: Горячие клавиши, SSE-уведомления, Модерация статей, Идеи и Загрузка фото

## 1. Обзор требований и цели
На основе запроса пользователя и полученных ответов планируется внедрение пяти ключевых модулей:

1. **Полноценная работа горячих клавиш (Keyboard Shortcuts)**:
   - Исправление глобального обработчика клавиш для стабильной работы независимо от текущей раскладки клавиатуры (русская, английская, `e.code` vs `e.key`).
   - Добавление интуитивных сочетаний: `Ctrl/Cmd + K` (быстрый поиск), `Ctrl/Cmd + N` (новая статья), `Ctrl/Cmd + H` (главная), `Ctrl/Cmd + I` (раздел идей), `Ctrl/Cmd + P` (статьи на рассмотрении), `Ctrl + Shift + R` (случайная статья), `Esc` (закрытие любых модалок и меню), `?` / `Shift + /` (справка).
   - Обновление интерактивного окна `KeyboardShortcutsModal` с подсказками.

2. **Меню и система уведомлений в реальном времени (Real-Time SSE & Toasts)**:
   - Бэкенд SSE эндпоинт `/api/events` с привязкой к сессии пользователя и рассылкой событий (изменение статуса статьи, отзыв с проверки, комментарии, реакции на идеи).
   - Фронтенд-контекст `NotificationContext` / хук `useRealtimeNotifications` с всплывающими тостами (toast notifications), звуковым/визуальным сигналом и счётчиком непрочитанных на колокольчике в шапке.
   - Улучшенное навигационное меню (мобильное и десктопное) со ссылками на все ключевые разделы платформы.

3. **Страница статей на рассмотрении («На рассмотрении» / `/review`)**:
   - Единый центр модерации и трекинга статуса статей для авторов и редакторов.
   - **Для авторов**:
     - Список собственных отправленных статей со статусом `pending_review` и `rejected`.
     - Отображение вердикта модератора с подробной причиной отказа или комментарием к принятию.
     - Возможность **отозвать статью с проверки** («Забрать на доработку») обратно в статус `draft` для внесения правок.
     - Возможность **удалить** статью или черновик.
   - **Для модераторов и администраторов**:
     - Список всех ожидающих проверку статей с фильтрами по категориям и авторам.
     - Модальное окно принятия статьи с возможностью оставить похвалу/комментарий.
     - Модальное окно отклонения статьи с обязательным выбором категории причины (например: *«Недостаточно авторитетных источников»*, *«Нарушение нейтральности или вайб-стиля»*, *«Некорректное оформление или форматирование»*, *«Дубликат существующей статьи»*, *«Своя причина»*) и текстовым пояснением.
     - Мгновенная отправка уведомления автору через SSE при принятии или отклонении.

4. **Страница предложений и идей («Идеи» / `/ideas`)**:
   - Новые таблицы в SQLite: `ideas` и `idea_votes`.
   - Возможность всем авторизованным пользователям создавать идеи по развитию платформы (категории: Функционал, Дизайн, Правила, Баги, Другое).
   - Система оценок: раздельные лайки (+1) и дизлайки (-1) с защитой от накрутки (один голос на пользователя с возможностью отмены).
   - Фильтры и сортировки: Популярные (по балансу голосов), Новые, В разработке, Реализованные.
   - Администраторские и модераторские статусы идей (Открыто, Запланировано, В процессе, Реализовано, Отклонено) с официальным ответом администрации.

5. **Загрузка собственных файлов фотографического формата (Upload System)**:
   - Поддерживаемые форматы изображений: JPG, PNG, WEBP, GIF, SVG.
   - Серверный эндпоинт `POST /api/upload`: валидация MIME-типа и размера (до 10 МБ), генерация уникального имени, безопасное сохранение в директорию `./uploads` (или `/app/uploads` в Docker).
   - Статическая раздача через Express `app.use('/uploads', express.static(...))`.
   - UI-компонент загрузки фотографий:
     - Кнопка «Загрузить фото» в редакторе статей (`ArticleEditPage` и `RichTextEditor`) с возможностью drag-and-drop, предпросмотром и мгновенной вставкой Markdown-тега `![Описание](/uploads/filename.webp)` в текст статьи.
     - Загрузка обложки статьи и аватара в профиле пользователя.

## 2. Архитектура и изменения в базе данных (SQLite)

### В `src/server/db.ts` и `server.ts`:
1. **Новые таблицы**:
   ```sql
   CREATE TABLE IF NOT EXISTS ideas (
     id TEXT PRIMARY KEY,
     title TEXT NOT NULL,
     description TEXT NOT NULL,
     category TEXT NOT NULL,
     author_id TEXT NOT NULL,
     author_name TEXT NOT NULL,
     author_username TEXT NOT NULL,
     author_avatar TEXT,
     author_role TEXT NOT NULL,
     created_at TEXT NOT NULL,
     status TEXT DEFAULT 'open',
     admin_response TEXT,
     likes_count INTEGER DEFAULT 0,
     dislikes_count INTEGER DEFAULT 0
   );

   CREATE TABLE IF NOT EXISTS idea_votes (
     idea_id TEXT NOT NULL,
     user_id TEXT NOT NULL,
     vote INTEGER NOT NULL, -- +1 или -1
     created_at TEXT NOT NULL,
     PRIMARY KEY (idea_id, user_id)
   );
   ```

2. **Расширение таблицы статей (`articles`)**:
   - Добавление полей (если отсутствуют):
     - `review_feedback TEXT` (причина отклонения или комментарий рецензента)
     - `reviewed_by TEXT` (имя модератора)
     - `reviewed_at TEXT` (дата рецензирования)

3. **Серверный менеджер SSE-подключений (`sseManager`)**:
   - Хранение пула активных соединений `Map<string, Response[]>` по `userId` (плюс широковещательный канал).
   - Функция `sendNotification(userId, notification)`: сохраняет в SQLite таблицу `notifications` и немедленно пушит событие `event: notification` через SSE клиенту.
   - Keep-alive пинг каждые 30 секунд для предотвращения обрыва прокси/шлюзами.

4. **Маршруты API**:
   - `GET /api/events` — Server-Sent Events поток для текущего пользователя.
   - `GET /api/articles/pending` — список статей на рассмотрении (для автора или модератора).
   - `POST /api/articles/:id/retract` — отзыв статьи автором на доработку (перевод в `draft`).
   - `POST /api/articles/:id/review` — принятие или отклонение статьи модератором с указанием причины.
   - `GET /api/ideas`, `POST /api/ideas`, `POST /api/ideas/:id/vote`, `PATCH /api/ideas/:id/status`.
   - `POST /api/upload` — загрузка фотографий/изображений с сохранением в `./uploads`.

## 3. Компоненты и страницы клиентской части (React)

1. **Глобальный хук и слушатель клавиш (`useKeyboardShortcuts` / `App.tsx`)**:
   - Обработка `e.code` (`KeyK`, `KeyN`, `KeyH`, `KeyI`, `KeyP`, `KeyR`, `Slash`, `Escape`) в дополнение к `e.key`, чтобы сочетания безупречно срабатывали как на русской, так и на английской раскладке.
   - Игнорирование срабатываний при фокусе в полях ввода, кроме `Escape`.

2. **Компонент и контекст уведомлений (`NotificationContext` & `ToastContainer`)**:
   - Подключение к `/api/events` при авторизации.
   - Анимированные всплывающие тосты в правом верхнем углу при поступлении новых событий.
   - Синхронизация счётчика непрочитанных в `Header` в реальном времени.

3. **Страница статей на рассмотрении (`src/pages/PendingReviewPage.tsx`)**:
   - Вкладки: «Мои заявки» (для всех авторов) и «Очередь модерации» (для редакторов/модераторов/админов).
   - Карточки статей со статусом: `pending_review` (Ожидает проверки), `rejected` (Отклонена), `draft` (Черновик/Отозвана).
   - Блок с подробной причиной отклонения и советами по исправлению.
   - Кнопка «Отозвать на доработку» и «Удалить» для автора.
   - Кнопки «Одобрить» и «Отклонить с причиной» для модераторов.

4. **Страница идей и предложений (`src/pages/IdeasPage.tsx`)**:
   - Список предложений с индикацией голосов (стрелки вверх/вниз или сердечки/пальцы), подсветкой активного выбора пользователя.
   - Бейджи статусов: «Открыто», «Запланировано», «В работе», «Реализовано», «Отклонено».
   - Ответ администрации в отдельной плашке.
   - Модальное окно «Предложить идею» с выбором категории и описанием.

5. **Модуль загрузки изображений (`ImageUploaderModal.tsx` & кнопки в редакторе)**:
   - Поддержка вставки перетаскиванием (drag-and-drop) и выбора файла через проводник.
   - Предпросмотр изображения перед загрузкой.
   - Мгновенное копирование ссылки и кнопка «Вставить в статью».

6. **Навигация и шапка (`Header.tsx` & меню)**:
   - Добавление ссылок «На рассмотрении» и «Идеи» в десктопное меню и мобильное всплывающее меню.
   - Обозначение горячих клавиш в выпадающих подсказках.

## 4. План проверки и тестирования
1. Запуск `compile_applet` и `lint_applet` для контроля TypeScript-типов и синтаксиса.
2. Проверка работы горячих клавиш при переключении раскладок (RU/EN).
3. Проверка SSE-уведомлений: создание статьи автором -> появление уведомления у модератора -> отклонение с причиной -> появление тоста и уведомления у автора.
4. Проверка отзыва статьи автором на доработку и повторной отправки.
5. Проверка создания идеи, голосования за и против, исключения повторных голосов.
6. Проверка загрузки фотографии через `/api/upload` и корректного отображения превью в статье.
7. Прогон набора тестов `npm run test:build`.
