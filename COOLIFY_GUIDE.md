# Руководство по развертыванию Вайбопедии на Coolify

Данное руководство объясняет, как задеплоить **Вайбопедию** на ваш сервер с помощью **Coolify**.

---

## Вариант 1: Развертывание через Git-репозиторий (Рекомендуемый)

1. Откройте панель **Coolify** и перейдите в ваш **Project / Environment**.
2. Нажмите **+ New** → Выберите **Public Repository** или **Private Repository (GitHub/GitLab)**.
3. Вставьте ссылку на репозиторий с Вайбопедией.
4. В настройках билда (**Build Pack**):
   - Выберите **Docker Compose** или **Dockerfile**.
   - Порт приложения: **3000**.
5. Монтирование тома для сохранения базы SQLite:
   - Том: `./data:/app/data` или `vibopedia_data:/app/data` (база данных `vibopedia.db` сохранится при перезапусках контейнера).
6. Нажмите **Deploy**.

---

## Вариант 2: Локальная установка через install.sh

Если вы разворачиваете проект прямо на VPS без Coolify или хотите протестировать локально:

```bash
chmod +x install.sh
./install.sh
```

После этого сервер запустится и создаст базу SQLite в `./data/vibopedia.db`.

---

## Главные переменные окружения (опционально)

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `PORT` | `3000` | Порт Express сервера |
| `NODE_ENV` | `production` | Окружение приложения |
| `GEMINI_API_KEY` | *(Опционально)* | API ключ Gemini для ИИ-помощника |
